NusaStatistik — a national statistics site for Indonesia, built from published Badan Pusat Statistik (BPS) figures. Dashboard plus linked sections for population, economy, prices, employment, and wellbeing, each with real figures carrying source and year, working charts, and controls that actually work (year picker, province search and sort, chart mode toggle). Static files only, no network requests, works on desktop and phone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
